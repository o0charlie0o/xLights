# xLights macOS Keyboard Shortcuts

Complete keyboard shortcut reference for the native macOS xLights rebuild.

## Playback & Transport

| Shortcut | Action |
|----------|--------|
| **Space** | Play/Pause toggle |
| **⌘.** | Stop |
| **⌘[** | Seek to Start |
| **⌘]** | Seek to End |

## Document Management

| Shortcut | Action |
|----------|--------|
| **⌘N** | New Sequence |
| **⌘O** | Open Sequence… |
| **⌘W** | Close |
| **⌘S** | Save |
| **⇧⌘S** | Save As… |
| **⌘P** | Print… |

## Symbol Key

- **⌘** = Command
- **⇧** = Shift
- **⌥** = Option
- **⌃** = Control

## Customization

Keyboard shortcuts follow macOS conventions. Some shortcuts can be customized in System Preferences > Keyboard > Shortcuts > App Shortcuts by targeting "xLights.app".
